# Архитектурный подход к быстрой кросс-языковой навигации по связанным сущностям в программных проектах
Данный репозиторий содержит исходный код проекта LanD Explorer [1], в который внедрено новое архитектурное решение, обеспечивающее быструю навигацию между GraphQL и Go.

Грамматики, лежащие в основе алгоритма связи:
1. [Методы Go](<LanD Specifications/grammars/golang_high_level.land>)
2. [Анонимные вызовы](<LanD Specifications/grammars/anon_calls.land>)
3. [Обычные вызовы](<LanD Specifications/grammars/pure_calls.land>)
4. [Управляющие операторы](<LanD Specifications/grammars/controls.land>)

Реализация алгоритма связи: [Automarkup.cs](<LandParserGenerator/Control/ControlPartial/Automarkup.cs>)
